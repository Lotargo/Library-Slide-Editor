# Стратегия и Архитектура Проекта

Мы создаем мощную платформу для организации рабочих пространств, сочетающую в себе удобство написания документов (как в Notion) и возможности создания презентационных материалов (Слайды).

## 🟢 Текущий Статус (Phase 1 Completed)
*   **Архитектура:** Переход на React + Django REST API завершен. Используется MongoDB (через Docker).
*   **Основные сущности:** Workspaces, Pages, Blocks работают.
*   **Блоки:** Реализованы Text, Slide, Table, Board, Calendar (MVP).
*   **Тулбар:** Есть, с возможностью скрытия.
*   **Slash Commands:** `/slide`, `/table`, `/board`, `/calendar` реализованы, но требуют доработки.

## ⚠️ Текущие Проблемы и Трудности (Challenges)
1.  **Тестирование Frontend (Playwright):**
    *   Возникли проблемы с автоматическими тестами через Playwright. Скрипты падают по тайм-ауту при ожидании появления элементов (например, после создания Workspace или при вводе Slash-команды).
    *   Вероятная причина: Асинхронная природа React и задержки рендеринга, которые скрипт не учитывает корректно, либо проблемы с селекторами в динамическом контенте.
2.  **Slash Commands (Ввод команд):**
    *   Текущая реализация `/slide` и других команд опирается на точное совпадение текста в блоке.
    *   При быстром вводе или автоматизированном вводе (как в тестах) событие может не срабатывать корректно, или React не успевает обновить состояние до проверки условия.
    *   Необходимо переписать логику на более надежную (например, отслеживание ввода символа `/` и открытие меню, или использование регулярных выражений при `onInput`).
