# Стратегия и Архитектура Проекта (Library)

Мы создаем мощную платформу "Library" для организации рабочих пространств, сочетающую в себе удобство написания документов (как в Notion) и возможности создания презентационных материалов (Слайды).

## 🟢 Текущий Статус (Phase 2 Active)
*   **Брендинг:** Проект переименован в **Library**. Обновлен логотип.
*   **Редактор:**
    *   Добавлена поддержка **Underline** (Floating Menu) и **Paste** (Context Menu).
    *   Исправлен визуальный баг с дублированием текста в CodeBlock.
    *   Слайды теперь можно **переименовывать** прямо в заголовке.
    *   Slash Commands (`/`) работают с выпадающим меню.
*   **Архитектура:** Переход на React + Django REST API завершен. Используется MongoDB (через Docker).
*   **Блоки:** Реализованы Text, Slide, Table, Board, Calendar, Code (PrismJS), Mermaid, Gallery, Checklist, Quote, Divider.

## ⚠️ Текущие Проблемы и Трудности (Challenges)
1.  **Тестирование Frontend (Playwright):**
    *   Автоматические тесты (особенно headless) иногда нестабильны из-за асинхронного рендеринга и фокуса (например, меню Slash команд).
2.  **Clipboard (Копирование блоков):**
    *   Копирование и вырезание отдельных *блоков* (как структур) пока не реализовано через системный буфер обмена (сейчас копируется только текст внутри блока). Требуется кастомная сериализация для вставки сложных структур.

## 🔜 Что осталось доделать (Remaining Tasks)
1.  **Drag-and-Drop:**
    *   Реализовать полноценное перетаскивание блоков внутри страницы и *внутрь* слайдов.
2.  **Улучшенное выделение (Multi-selection):**
    *   Реализовать возможность выделять несколько текстовых блоков мышью.
3.  **Копирование Блоков:**
    *   Реализовать Deep Copy для выбранных блоков (не только текста).
4.  **UI/UX Полировка:**
    *   Улучшить стили таблиц и канбан-досок.

## 🛠 Технический Стек

### Frontend
*   **React:** Основной фреймворк.
*   **Сборка:** Vite.
*   **Расположение:** `frontend/`.
*   **Стили:** Tailwind CSS v4.
*   **Libs:** `lucide-react` (иконки), `prismjs` (код), `mermaid` (диаграммы), `katex` (формулы).
*   **Formatting:** `document.execCommand` для базового форматирования текста (bold, italic, underline).

### Backend
*   **Django:** REST API (MongoDB via PyMongo).
